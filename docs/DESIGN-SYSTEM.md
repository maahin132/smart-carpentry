# Smart Carpentry — Design System

## 1. Purpose

This document defines the visual and interaction principles for the Smart Carpentry platform.

The design system exists to keep the product visually consistent across:

- Public website
- User workspace
- Estimator
- Cutting optimizer
- Quotations
- Authentication
- Administration

The interface should feel like a professionally designed woodworking, interior, and construction product rather than a generic technology or AI landing page.
